# 链接哨兵（LinkSentinel）设计

原生 macOS 13+ 菜单栏链接监控工具，使用 SwiftUI、AppKit、URLSession、UserNotifications、SQLite，无第三方依赖。

## 用户要求

- 灰、绿、黄、红圆形菜单栏图标；双击打开窗口。
- 打开窗口显示 Dock 图标；关闭窗口隐藏 Dock 图标，保留菜单栏；最小化保留 Dock 图标。
- 链接默认 https://www.gstatic.com/generate_204；每次打开窗口聚焦链接并全选。
- 告警阈值默认 1000 毫秒，间隔默认 5 秒；开启/停止按钮。
- 监控按钮旁提供“重置”，停止时可恢复默认链接、阈值和间隔并清除保存的自定义设置，保留历史；监控或准备启动时禁用。
- 状态：未开启（灰）、监控中（绿）、延迟高（黄）、失败（红）。
- 请求历史：开始时间、链接、耗时、是否触发通知。
- 历史表格绑定原生多选状态，右键菜单针对点击行或所选多行复制；⌘C 复制选中记录。复制完整五列，以制表符和换行分隔，顺序与表格一致；翻页或刷新时清理已离开当前页的选择。
- 请求不通或过慢时发系统通知。

## 实现约定

- AppKit 管理菜单栏、右键菜单和窗口；SwiftUI 呈现中文设置及表格。
- 开启时立即 HEAD，收到响应头时结束计时，不读取正文、不跟随重定向；禁用缓存。阈值仅用于完成后的告警判定，不会中断请求；超过阈值标记延迟高并通知。传输错误或 HTTP 错误优先标记失败；底层网络超时沿用 URLSession 默认设置。
- HTTP 200...399（含 204）为有效响应；耗时超限为黄色延迟高；HTTP 400...599、DNS/TLS/断网错误为红色失败。不对 405 回退 GET。展示具体原因，下次成功恢复绿色。
- 相邻请求开始时间至少间隔设定秒数；串行执行，超过间隔不补发积压请求。睡眠期间不请求，唤醒后继续。
- 停止取消请求与等待；取消中的请求仍记历史，标记“已取消”，不通知。关闭窗口继续监控；退出终止监控；重启不自动开启。
- 告警阈值为正整数毫秒（最大 3600000）；间隔为 0.1...86400 秒。监控时锁定输入，停止后修改。
- 通知首次开启时请求权限；拒绝后仍监控，但明确显示未授权。列表区分未触发、已发送、未授权和发送失败；“已发送”代表系统接受请求，不保证专注模式下出现横幅。
- 配置通过 UserDefaults 保存；所有历史写入本机 SQLite，分页显示，不自动清理。数据库错误显示于窗口，不悄悄重建或覆盖数据。
- 1.0.3 一次性将旧默认 Google 首页升级为 204 地址，保留其他配置；历史沿用 timeout 存储值，新显示文案为“延迟高”。
- 项目同时提供 Xcode 工程、Swift Package 自动测试和构建脚本，输出带 Info.plist 和本地签名的 .app。

## 验证

验证输入校验、HEAD/204、响应头计时、不跟随重定向、慢响应、HTTP/网络错误、请求取消、停止竞态、默认地址迁移、恢复绿色、SQLite 重启/分页；编译 Xcode 工程并启动应用检查 GUI。
