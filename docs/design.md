# 链接哨兵（LinkSentinel）设计

原生 macOS 13+ 菜单栏链接监控工具，使用 SwiftUI、AppKit、URLSession、UserNotifications、SQLite，无第三方依赖。

## 用户要求

- 灰、绿、黄、红圆形菜单栏图标；双击打开窗口。
- 打开窗口显示 Dock 图标；关闭窗口隐藏 Dock 图标，保留菜单栏；最小化保留 Dock 图标。
- 链接默认 https://www.google.com；每次打开窗口聚焦链接并全选。
- 请求时长默认 1000 毫秒，间隔默认 5 秒；开启/停止按钮。
- 状态：未开启（灰）、监控中（绿）、超时（黄）、失败（红）。
- 请求历史：开始时间、链接、耗时、是否触发通知。
- 请求不通或过慢时发系统通知。

## 实现约定

- AppKit 管理菜单栏、右键菜单和窗口；SwiftUI 呈现中文设置及表格。
- 开启时立即 GET，完整响应计时；禁用缓存。阈值仅用于完成后的告警判定，不会中断请求；完整响应结束后保存总耗时，超过阈值标记超时并通知。传输错误或 HTTP 错误优先标记失败；底层网络超时沿用 URLSession 默认设置。
- HTTP 200...399 为正常；耗时超限为黄色超时；HTTP 400...599、DNS/TLS/断网错误为红色失败。展示具体原因，下次成功恢复绿色。
- 相邻请求开始时间至少间隔设定秒数；串行执行，超过间隔不补发积压请求。睡眠期间不请求，唤醒后继续。
- 停止取消请求与等待；取消中的请求仍记历史，标记“已取消”，不通知。关闭窗口继续监控；退出终止监控；重启不自动开启。
- 请求时长为正整数毫秒（最大 3600000）；间隔为 0.1...86400 秒。监控时锁定输入，停止后修改。
- 通知首次开启时请求权限；拒绝后仍监控，但明确显示未授权。列表区分未触发、已发送、未授权和发送失败；“已发送”代表系统接受请求，不保证专注模式下出现横幅。
- 配置通过 UserDefaults 保存；所有历史写入本机 SQLite，分页显示，不自动清理。数据库错误显示于窗口，不悄悄重建或覆盖数据。
- 项目同时提供 Xcode 工程、Swift Package 自动测试和构建脚本，输出带 Info.plist 和本地签名的 .app。

## 验证

验证输入校验、慢请求及完整响应体总耗时、HTTP/网络错误、请求取消、停止竞态、恢复绿色、SQLite 重启/分页；编译 Xcode 工程并启动应用检查 GUI。
