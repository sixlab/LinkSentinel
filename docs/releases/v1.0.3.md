# 链接哨兵 v1.0.3

构建 9 · macOS 13+ · Apple Silicon / Intel 通用版

## 更新内容

- 改用 HTTP HEAD 请求，记录从发起请求到收到响应头的耗时，不下载正文、不跟随重定向。
- 默认地址更新为 `https://www.gstatic.com/generate_204`。升级时一次性替换已保存的旧默认 Google 首页，保留自定义地址、阈值和间隔。
- 黄色“超时”状态更名为“延迟高”，同步更新历史记录和通知文案。
- 新增“重置”按钮，停止监控时可恢复默认地址、1000 毫秒告警阈值和 5 秒间隔，保留历史记录。
- 历史列表支持单选、⌘ / Shift 多选、右键复制行和 ⌘C。按列表顺序复制完整日期时间、链接、响应耗时、结果和通知状态，以制表符分列。

## 测速说明

告警阈值不会主动中断请求。HEAD 响应完成后才记录耗时并判断是否通知；底层网络超时仍遵循系统规则。本版耗时不包含响应正文下载，旧版历史数值保持不变。

请求方式对齐 Mihomo 普通 URLTest，未实现“统一延迟”的第二次请求机制；代理路径和网络栈也可能导致与 Clash 显示的数值不同。返回 HTTP 405 的地址会记录为失败，不自动回退 GET。

## 安装与校验

下载 `LinkSentinel-v1.0.3-macOS-universal.zip`，解压后将 `链接哨兵.app` 拖入“应用程序”。升级前先用 ⌘Q 退出旧版；配置、历史记录和应用标识保留。

应用使用 ad-hoc 签名，尚未使用 Developer ID 签名或经 Apple 公证。首次打开可能被 Gatekeeper 拦截；确认来源可信后参考 [Apple 打开说明](https://support.apple.com/en-us/102445)，或从源码自行构建。

下载 ZIP 和 `SHA256SUMS.txt` 后，在同一目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 验证

27 项自动测试覆盖 HEAD / HTTP 204、响应头计时、不跟随重定向、慢响应、失败判定、手动取消、设置迁移和 SQLite 历史。原生窗口已验证行选中、多选与右键菜单。发布包包含 arm64 和 x86_64，解压后核验应用版本与签名。

## English

Build 9. A native macOS 13+ menu bar URL monitor for Apple Silicon and Intel.

- Switch to HEAD requests and measure time to response headers, without downloading a body or following redirects.
- Default to `https://www.gstatic.com/generate_204`. Upgrade the saved old Google homepage default once, preserving custom URLs, thresholds, and intervals.
- Rename the yellow status to `延迟高` (high latency), including history and notification wording.
- Add a Reset button to restore the default URL, 1,000 ms threshold, and 5-second interval while stopped, preserving history.
- Select one or multiple history rows and copy all five columns in display order using the context menu or ⌘C. Output uses full timestamps and tab-separated columns.

The alert threshold does not cancel requests. Timing now ends when HEAD response headers arrive; historical durations remain unchanged. The optional second request used by Mihomo's unified delay is not implemented, and proxy routing or network-stack differences can also affect comparisons with Clash. HTTP 405 responses remain failures without a GET fallback.

Download the universal ZIP, extract it, and drag `链接哨兵.app` into Applications. Quit older versions before upgrading. Settings, history, and the application identifier are preserved. Builds are ad-hoc signed and are not Apple-notarized; see [Apple's launch guidance](https://support.apple.com/en-us/102445) if Gatekeeper blocks the app, or build from source.

Verify the ZIP with `shasum -a 256 -c SHA256SUMS.txt`. Release validation covers 27 automated tests, native row-selection/context-menu checks, both CPU architectures, and signature verification after extraction.
