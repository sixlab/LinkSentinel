# 链接哨兵 v1.0.2

首次公开发布 · 构建 6 · macOS 13+

原生 macOS 菜单栏链接监控工具，支持 Apple Silicon 和 Intel。

## 功能

- 定时请求自定义链接，完成后记录请求总耗时；超过告警阈值不会主动取消。
- 慢响应和请求失败触发系统通知，菜单栏提供灰、绿、黄、红四种状态。
- 关闭窗口后继续监控，双击菜单栏圆点打开窗口。
- 本机 SQLite 保存全部请求历史，配置自动保存。
- 中文界面、中英文 README、MIT 许可证。

## 安装

下载 `LinkSentinel-v1.0.2-macOS-universal.zip`，解压并将 `链接哨兵.app` 拖入“应用程序”。升级前用 ⌘Q 退出旧版。首次点击“开启监控”时允许系统通知。

应用使用 ad-hoc 签名，尚未使用 Developer ID 签名或经 Apple 公证。首次打开可能被 Gatekeeper 拦截；确认来源可信后参考 [Apple 打开说明](https://support.apple.com/en-us/102445)，或从源码自行构建。

下载 ZIP 和 `SHA256SUMS.txt` 后，在同一目录运行 `shasum -a 256 -c SHA256SUMS.txt` 验证文件完整性。

## 验证

22 项自动测试通过，覆盖完整慢响应、流式响应总耗时、失败判定、手动取消、SQLite 历史和设置迁移。发布包包含 arm64 与 x86_64，已验证应用签名及解压后的包结构。

## English

First public release, build 6. A native macOS 13+ menu bar URL monitor for Apple Silicon and Intel.

- Periodically checks a configurable URL and records the duration of the full response. The alert threshold does not cancel requests.
- Sends macOS notifications for slow or failed requests and displays four status colors in the menu bar.
- Keeps monitoring when the window is closed; double-click the menu bar dot to reopen it.
- Saves settings and complete request history locally.
- Includes a Simplified Chinese interface, Chinese and English documentation, and the MIT license.

Download the universal ZIP, extract it, and drag `链接哨兵.app` into Applications. Quit older versions before upgrading. Release builds are ad-hoc signed and are not Apple-notarized; see [Apple's launch guidance](https://support.apple.com/en-us/102445) if Gatekeeper blocks the app, or build from source.

Verify the ZIP with `shasum -a 256 -c SHA256SUMS.txt`. The release is validated with 22 passing tests, both CPU architectures, and signature verification after extraction.
