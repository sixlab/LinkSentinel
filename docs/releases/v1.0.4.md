# 链接哨兵 v1.0.4

构建 10 · macOS 13+ · Apple Silicon / Intel 通用版

## 更新内容

- 新增“连续异常次数”输入框，默认 **3**，支持正整数校验、保存和重置。
- 延迟高和请求失败混合累计，每连续达到设定次数通知一次；默认在第 **3、6、9…次**异常时分别通知。
- 正常请求、取消或停止监控后清零，重新开启不会继承之前的计数。设为 **1** 时，每次异常都通知。
- 状态颜色仍立即反映每次请求结果；历史详情包含当前这一轮的异常计数，未达到次数的记录不会触发通知。
- 升级时为旧配置新增默认次数 **3**，保留已有链接、阈值、间隔和历史记录。
- 中英文 README 新增纯 AI 开发说明：人提出需求和反馈，AI 完成实现、测试、文档、构建及发布。

## 安装与校验

下载 `LinkSentinel-v1.0.4-macOS-universal.zip`，解压后将 `链接哨兵.app` 拖入“应用程序”。升级前用 ⌘Q 退出旧版。

应用使用 ad-hoc 签名，尚未使用 Developer ID 签名或经 Apple 公证。首次打开可能被 Gatekeeper 拦截；确认来源可信后参考 [Apple 打开说明](https://support.apple.com/en-us/102445)，或从源码自行构建。

下载 ZIP 和 `SHA256SUMS.txt` 后，在同一目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## 验证

36 项自动测试覆盖通知次数、混合异常、正常请求与重启清零、自定义次数、配置保存、重置、非法输入和旧配置兼容，以及原有网络与历史功能。原生窗口已确认新增输入框默认值与监控时禁用行为。发布包包含 arm64 和 x86_64，解压后核验应用版本与签名。

## English

Build 10. A native macOS 13+ menu bar URL monitor for Apple Silicon and Intel.

- Add a persisted positive-integer consecutive-anomaly input, defaulting to **3** and included in Reset.
- Count high latency and request failures together, notifying after each group: by default, the **3rd, 6th, 9th…** consecutive anomaly.
- Clear the pending count after a normal response, cancellation, or stopping. Restarting begins a new count. Set the limit to **1** to notify on every anomaly.
- Keep status colors immediate and include the current group count in history details. Earlier rows do not trigger a notification.
- Preserve existing settings and history, adding the default limit of **3** when reading older configurations.
- Explain in both READMEs that the project is developed entirely by AI, with humans providing requirements and feedback.

Download the universal ZIP, extract it, and drag `链接哨兵.app` into Applications. Quit older versions before upgrading. Builds are ad-hoc signed and are not Apple-notarized; see [Apple's launch guidance](https://support.apple.com/en-us/102445) if Gatekeeper blocks the app, or build from source.

Verify the ZIP with `shasum -a 256 -c SHA256SUMS.txt`. Release validation includes 36 automated tests, native input checks, both CPU architectures, and signature verification after extraction.
