# 链接哨兵 v1.0.5

构建 11 · macOS 13+ · Apple Silicon / Intel 通用版

## 更新内容

- **按固定间隔发起请求。** 例如间隔 5 秒时，在 00:00、00:05、00:10 发起请求；即使前一个请求尚未结束，也会继续发起下一个请求。
- **达到阈值立即判定。** 请求达到告警阈值仍未完成时，立即记录“延迟高”；网络或 HTTP 错误立即记录“失败”，并计入连续异常次数。
- **保留完整耗时。** 阈值不会取消请求。请求完成后更新同一条历史记录的实际耗时，不重复计数或通知；等待期间显示耗时下限。
- 并发请求按判定事件的先后累计异常，每累计设定次数通知一次；正常判定、取消或停止清零。已判定延迟高的请求后来成功，不会再次参与计数，迟到的完成结果不会覆盖较新状态。
- 修复界面线程卡顿可能把已正常返回的请求误判为延迟高的问题；通知发送不阻塞后续请求。
- 停止时取消全部进行中的请求，退出前等待历史落盘；兼容已有配置和历史，重启时恢复上次中断的记录。

例如间隔 **5 秒**、阈值 **1000 毫秒**、连续异常 **2 次**，且每次请求耗时 8 秒：

| 请求 | 发起 | 判定异常 | 完成 |
| --- | --- | --- | --- |
| 第一次 | 00:00 | 00:01 | 00:08 |
| 第二次 | 00:05 | **00:06，发送通知** | 00:13 |
| 第三次 | 00:10 | 00:11，重新累计第 1 次 | 00:18 |

时间为理想调度示例；系统睡眠或调度延迟后会跳过积压时段，不集中补发请求。

## 安装与校验

下载 `LinkSentinel-v1.0.5-macOS-universal.zip`，解压后将 `链接哨兵.app` 拖入“应用程序”。升级前用 ⌘Q 退出旧版。已有配置、历史与通知授权保留。

应用使用 ad-hoc 签名，尚未使用 Developer ID 签名或经 Apple 公证。首次打开可能被 Gatekeeper 拦截；确认来源可信后参考 [Apple 打开说明](https://support.apple.com/en-us/102445)，或从源码自行构建。

下载 ZIP 和 `SHA256SUMS.txt` 后，在同一目录运行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

## English

Build 11. A native macOS 13+ menu bar URL monitor for Apple Silicon and Intel.

- Launch requests at fixed intervals, allowing overlap. With a 5-second interval, requests start at 00:00, 00:05, and 00:10 regardless of earlier responses.
- Immediately mark unfinished requests as high latency at the alert threshold. Record network and HTTP failures as soon as they occur and count each request only once toward the anomaly limit.
- Let slow requests finish, then update the same history row with the final duration without recounting or notifying again. Show a lower-bound duration while waiting.
- Count anomalies in detection order and notify after every configured group. Normal verdicts, cancellation, or stopping clear the pending count. Eventual success after a high-latency verdict is not a new verdict; late completions cannot replace newer status.
- Prevent UI stalls from misclassifying completed normal requests as high latency. Notification delivery does not block future requests.
- Cancel all in-flight requests on stop, await persistence on quit, and recover interrupted rows on restart while preserving existing settings and history. Skip missed intervals after sleep or scheduling delays instead of sending a burst of requests.

For 5-second intervals, a 1,000 ms threshold, an anomaly limit of 2, and 8-second responses, the first two requests are judged slow around 00:01 and 00:06. The first notification is triggered around 00:06, before either request has completed.

Download the universal ZIP, extract it, and drag `链接哨兵.app` into Applications. Quit older versions before upgrading. Builds are ad-hoc signed and are not Apple-notarized; see [Apple's launch guidance](https://support.apple.com/en-us/102445) if Gatekeeper blocks the app, or build from source.

Verify the ZIP with `shasum -a 256 -c SHA256SUMS.txt`. Release validation includes 46 automated tests, native monitoring checks, both CPU architectures, and signature verification after extraction.
